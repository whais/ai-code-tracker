## ✨ 功能特性

### 核心功能
- 🎯 **AI代码识别**：自动检测并标记 AI 生成的代码
- 🏷️ **自定义标记模式**：支持配置正则表达式匹配项目中已有的 AI 标记
- 👥 **团队统计**：按成员统计 AI 使用率，支持 Git 集成
- 📊 **实时监控**：状态栏实时显示个人和团队 AI 使用率
- 🏷️ **手动标记**：支持手动标记代码为 AI 或人工编写
- 📈 **Git 历史分析**：分析整个项目的 Git 历史，追溯代码来源

### 周报功能
- 📧 **自动生成周报**：每周自动生成团队 AI 使用报告
- 📄 **多格式导出**：支持 HTML、Markdown、JSON 格式
- 📊 **可视化展示**：进度条、趋势图、排行榜
- 💡 **智能建议**：基于数据分析提供改进建议
- 🎨 **精美模板**：现代化设计的报告界面

### 标记配置功能 (v1.1.0 新增)
- 🔧 **自定义正则模式**：添加任意正则表达式匹配项目中的 AI 标记
- 📋 **内置预设模式**：支持 DeepSeek、Copilot、ChatGPT、Claude、Cursor、TabNine、Codeium 等
- 🧪 **模式测试工具**：实时测试正则表达式是否匹配
- 🎨 **多种标记格式**：支持注释格式、标签格式、自定义模板
- 📝 **模板变量支持**：`{model}`、`{timestamp}`、`{date}` 等动态变量

### 技术亮点
- 🔍 **Git Blame 集成**：精确到每一行代码的作者
- 🚀 **高性能分析**：增量分析，不影响开发体验
- 🔧 **高度可配置**：灵活的配置选项
- 📦 **零依赖**：纯 TypeScript 实现

## 🔧 AI 标记配置

### 为什么需要自定义标记？

如果您的项目中已经存在 AI 代码标记（如 @ai-generated、// AI: generated by xxx 等），插件可能无法识别。通过自定义标记模式，您可以告诉插件如何识别这些已有标记。

### 配置 AI 标记模式

1. 打开命令面板（Cmd/Ctrl + Shift + P）

2. 输入 AI Code Tracker: 配置 AI 标记模式

3. 选择操作：

📋 查看当前标记模式
显示所有已配置的 AI 标记模式，包括内置和自定义的。

➕ 添加自定义标记模式
添加新的正则表达式模式来匹配项目中的 AI 标记：
```json
{
  "name": "my-ai-tool",
  "patterns": [
    "@ai-generated",
    "// AI: generated by",
    "\\[CUSTOM-AI\\]"
  ],
  "description": "我的自定义 AI 工具",
  "enabled": true
}
```

✏️ 编辑标记模式
修改现有模式的配置、启用/禁用、编辑正则表达式等。

🗑️ 删除自定义标记模式
移除不再需要的自定义模式。

⚙️ 配置标记格式
设置新添加的 AI 标记的格式：

- 注释格式: // [AI-GEN] model={model} timestamp={timestamp}

- 标签格式: [AI-GEN] model={model} timestamp={timestamp}

- 自定义格式: 使用自定义模板

🔍 测试标记模式
测试您的正则表达式是否能正确匹配 AI 代码标记。

### 内置标记模式

插件内置了以下常见 AI 工具的标记模式：

工具名称	        识别模式
DeepSeek	       [AI-GEN] model=deepseek, [DEEPSEEK], Generated by DeepSeek, @deepseek
GitHub Copilot	 [AI-GEN] model=copilot, [GITHUB-COPILOT], Generated by Copilot, @copilot
Claude	         [AI-GEN] model=claude, [CLAUDE], Generated by Claude, @claude, Anthropic
ChatGPT	         [AI-GEN] model=chatgpt, [CHATGPT], Generated by ChatGPT, @openai
Cursor	         [AI-GEN] model=cursor, [CURSOR], Generated by Cursor, @cursor
TabNine	         [AI-GEN] model=tabnine, [TABNINE], Generated by TabNine, @tabnine
Codeium	         [AI-GEN] model=codeium, [CODEIUM], Generated by Codeium, @codeium

### 自定义模板变量

在自定义标记格式中，可以使用以下变量：

变量	       说明	            示例
{model}	    AI 模型名称	      deepseek-v3
{timestamp}	ISO 格式时间戳	  2026-03-27T10:30:00.000Z
{date}	    本地日期格式	    2026/3/27

示例模板：
```text
// @ai-generated by {model} on {date}
```
输出结果：
```js
// @ai-generated by deepseek-v3 on 2026/3/27
```

## ⚙️ 配置说明

### 完整配置示例

在 VSCode 设置（settings.json）中：

```json
{
  // 启用 Git 集成
  "aiCodeTracker.enableGitIntegration": true,
  
  // 团队成员映射
  "aiCodeTracker.teamMembers": {
    "zhangsan@company.com": "张三",
    "lisi@company.com": "李四"
  },
  
  // 自定义 AI 标记模式 (v1.1.0 新增)
  "aiCodeTracker.aiMarkPatterns": [
    {
      "name": "custom-deepseek",
      "patterns": ["@ai-generated", "// AI:", "\\[CUSTOM\\]"],
      "description": "项目自定义的 AI 标记",
      "enabled": true
    }
  ],
  
  // AI 标记格式 (v1.1.0 新增)
  "aiCodeTracker.markFormat": "comment",
  "aiCodeTracker.customMarkTemplate": "// [AI-GEN] model={model} timestamp={timestamp}",
  "aiCodeTracker.defaultModel": "ai",
  
  // 自动检测阈值
  "aiCodeTracker.autoDetectThreshold": 3,
  
  // 周报配置
  "aiCodeTracker.weeklyReport": {
    "enabled": true,
    "dayOfWeek": 5,
    "hour": 17,
    "minute": 0,
    "outputPath": "ai-reports",
    "format": "html",
    "useGit": true,
    "autoSend": false,
    "emailRecipients": ["team-leader@company.com"]
  },
  
  // 自动添加成员时显示通知
  "aiCodeTracker.notifyOnTeamMemberAdd": true
}
```

### 配置项说明

配置项	                 类型	       默认值	                                             说明
enableGitIntegration	  boolean	   true	                                              启用 Git Blame 分析
teamMembers	            object	   {}	                                                团队成员邮箱与名称映射
aiMarkPatterns	        array	     []	                                                自定义 AI 标记模式 (v1.1.0)
markFormat	            string	   "comment"	                                        标记格式: comment/tag/custom (v1.1.0)
customMarkTemplate	    string	   "// [AI-GEN] model={model} timestamp={timestamp}"	自定义标记模板 (v1.1.0)
defaultModel	          string	   "ai"	                                              默认 AI 模型名称 (v1.1.0)
autoDetectThreshold	    number	   3	                                                自动检测 AI 代码的阈值 (v1.1.0)
weeklyReport.enabled	  boolean	   false	                                            是否启用自动周报
weeklyReport.dayOfWeek	number	   5	                                                周报生成日期（0-6，0=周一）
weeklyReport.hour	      number	   17	                                                生成时间（0-23）
weeklyReport.format	    string	   "html"	                                            报告格式: html/markdown/json
weeklyReport.useGit	    boolean	   true	                                              使用 Git 历史生成报告 (v1.1.0)
notifyOnTeamMemberAdd	  boolean	   true	                                              添加成员时显示通知


## 👥 团队统计

### 统计维度

#### 个人维度

  - 总代码行数

  - AI 生成代码行数

  - 人工编写代码行数

  - AI 使用率

  - 各文件详细统计

#### 团队维度

  - 团队平均 AI 使用率

  - 成员 AI 使用率排行

  - 成员贡献占比

  - 趋势分析（环比变化）

### 统计原理

1. Git Blame 分析：获取每行代码的作者信息

2. 代码标记识别：解析注释中的 [AI-GEN] 和 [HUMAN] 标记

3. 实时统计：切换文件时自动更新统计


## 📊 周报功能

### 手动生成周报

1. 命令面板执行 AI Code Tracker: 生成周报

2. 等待分析完成（通常几秒钟）

3. 报告自动在浏览器中打开

### 自动周报

配置后，插件会在指定时间自动生成周报并保存到项目目录。

### 报告内容

#### 1. 总体概览

  - 总代码行数

  - AI 生成代码数量和占比

  - 人工编写代码数量

  - 活跃成员数量

#### 2. 团队排行

  - 按 AI 使用率排序

  - 显示趋势变化（↑/↓）

  - 贡献占比统计

#### 3. 本周之星

  - AI 使用达人（AI 代码最多）

  - 人工编码达人（人工代码最多）

#### 4. 智能建议

基于数据分析自动生成改进建议：

  - AI 使用率变化提醒

  - 团队协作建议

  - 代码质量提示

### 报告格式

#### HTML 格式（推荐）

  - 精美的现代化设计

  - 响应式布局

  - 可视化图表

  - 适合邮件发送和分享

#### Markdown 格式

  - 纯文本格式

  - 适合文档记录

  - 易于版本控制

#### JSON 格式

## ❓ 常见问题

### Q: 插件如何识别 AI 生成的代码？
A: 通过两种方式：

自动检测：从常见 AI 工具粘贴时自动识别

手动标记：通过注释 [AI-GEN] 标记

### Q: 为什么我的 AI 使用率显示为 0？
A: 可能的原因：

尚未标记任何代码为 AI 生成

Git 配置不正确（团队统计需要）

项目不在 Git 仓库中

### Q: 如何统计历史代码的 AI 使用率？
A: 使用 AI Code Tracker: 分析Git历史 命令，插件会分析所有提交记录。

### Q: 周报可以自动发送邮件吗？
A: 目前需要配置 SMTP 服务器，后续版本会内置邮件发送功能。

### Q: 支持哪些编程语言？
A: 支持主流编程语言：JavaScript、TypeScript、Python、Java、Go、Rust、C/C++、Ruby、PHP 等。

### Q: 会影响 VSCode 性能吗？
A: 不会。插件采用增量分析，只在文件切换时更新统计，不影响编辑体验。

### Q: 可以导出统计数据吗？
A: 可以。周报功能支持导出 JSON 格式，方便二次处理。
