## ✨ 功能特性

- 🧠 **智能粘贴**：粘贴 AI 代码时自动检测并提示标记

- 🎨 **多种标记格式**：支持头部注释、行内注释、块级标记
- 📝 **模板变量支持**：`{model}`、`{timestamp}`、`{date}`、`{author}` 等动态变量

### 技术亮点

- 🚀 **高性能分析**：增量分析，不影响开发体验

## 🏷️ 标记格式规范

### AI 生成代码标记

#### 1. 头部注释格式（推荐用于新文件）

**JSDoc 风格**（JavaScript/TypeScript）：
```typescript
/**
 * @ai-generated by deepseek
 * @date 2026-03-27
 * @description 用户管理模块
 */
```

**HTML/Vue 风格**：
```html
<!--
@ai-generated by copilot
@date 2026-03-27
@description 页面布局组件
-->
```

**Python 风格**：
```python
"""
@ai-generated by chatgpt
@date 2026-03-27
@description 数据处理模块
"""
```

#### 2. 行内注释格式（推荐用于单行修改）

```typescript
// @ai-generated: 2026-03-27 添加错误处理
const result = await fetchData();

# @ai-generated: 2026-03-27 优化算法
sorted_data = quick_sort(data)
```

#### 3. 块级标记格式（推荐用于多行代码块）

```typescript
// @ai-generated-start by deepseek 2026-03-27 实现排序算法
function quickSort(arr: number[]): number[] {
  if (arr.length <= 1) return arr;
  const pivot = arr[0];
  const left = arr.slice(1).filter(x => x < pivot);
  const right = arr.slice(1).filter(x => x >= pivot);
  return [...quickSort(left), pivot, ...quickSort(right)];
}
// @ai-generated-end
```

#### 4. 标签格式

```typescript
// [AI-GEN] model=deepseek timestamp=2026-03-27T10:30:00.000Z
const helper = () => {};
```

#### 5. JSON 文件标记

对于 JSON 文件，创建同名 `.generated` 标记文件：
```bash
# config.json 对应的标记文件
config.json.generated
```

内容示例：
```
@ai-generated by copilot
@date 2026-03-27
@description API 配置文件
```

### 人工编写代码标记

#### 1. 行内标记

```typescript
// @human-written by zhangsan 2026-03-27 修复边界情况
function validateInput(input: string): boolean {
  // 自定义验证逻辑
}
```

#### 2. 块级标记

```typescript
// @human-start by lisi 2026-03-27 核心业务逻辑
function calculateRevenue(orders: Order[]): number {
  // 复杂的人工计算逻辑
  return orders.reduce((sum, order) => sum + order.amount, 0);
}
// @human-end
```

#### 3. 标签格式

```typescript
// [HUMAN] author=wangwu timestamp=2026-03-27T10:30:00.000Z
```

## 🔧 AI 标记配置

### 为什么需要自定义标记？

如果您的项目中已经存在 AI 代码标记（如 `@ai-generated`、`// AI: generated by xxx` 等），插件可能无法识别。通过自定义标记模式，您可以告诉插件如何识别这些已有标记。

### 配置 AI 标记模式

1. 打开命令面板（Cmd/Ctrl + Shift + P）
2. 输入 `AI Code Tracker: 配置 AI 标记模式`
3. 选择操作：

#### 📋 查看当前标记模式
显示所有已配置的 AI 标记模式，包括内置和自定义的。

#### ➕ 添加自定义标记模式
添加新的正则表达式模式来匹配项目中的 AI 标记：
```json
{
  "name": "my-ai-tool",
  "patterns": [
    "@ai-generated",
    "// AI:",
    "\\[CUSTOM-AI\\]"
  ],
  "description": "我的自定义 AI 工具",
  "enabled": true,
  "extractAuthor": true,
  "authorPattern": "by\\s+(\\w+)",
  "extractTool": true,
  "toolPattern": "@ai-generated"
}
```

#### ✏️ 编辑标记模式
修改现有模式的配置、启用/禁用、编辑正则表达式等。

#### 🗑️ 删除自定义标记模式
移除不再需要的自定义模式。

#### ⚙️ 配置标记格式
设置新添加的 AI 标记的格式：
- **注释格式**: `// [AI-GEN] model={model} timestamp={timestamp}`
- **标签格式**: `[AI-GEN] model={model} timestamp={timestamp}`
- **块级格式**: 使用 `@ai-generated-start` / `@ai-generated-end`
- **自定义格式**: 使用自定义模板

#### 🔍 测试标记模式
测试您的正则表达式是否能正确匹配 AI 代码标记。

### 内置标记模式

插件内置了以下常见的 AI 标记模式：

| 模式名称 | 描述 | 匹配示例 |
|---------|------|----------|
| `jsdoc-header` | JSDoc 头部注释 | `/** @ai-generated by xxx */` |
| `html-header` | HTML/Vue 头部注释 | `<!-- @ai-generated by xxx -->` |
| `hash-header` | Python/Shell 头部注释 | `# @ai-generated by xxx` 或 `""" @ai-generated` |
| `css-header` | CSS 头部注释 | `/* @ai-generated by xxx */` |
| `inline-comment` | 行内注释格式 | `// @ai-generated: YYYY-MM-DD` |
| `block-start` | 块开始标记 | `// @ai-generated-start` |
| `block-end` | 块结束标记 | `// @ai-generated-end` |
| `jsx-inline` | JSX 行内注释 | `{/* @ai-generated: YYYY-MM-DD */}` |
| `sql-comment` | SQL 注释格式 | `-- @ai-generated: YYYY-MM-DD` |
| `generic-ai` | 通用 AI 标记 | `@ai-generated`, `[AI-GEN]`, `AI-generated` |
| `human` | Human 标记 | `@human`, `[HUMAN]`, `human-written` |
| `human-block-start` | Human 块开始 | `@human-start` |
| `human-block-end` | Human 块结束 | `@human-end` |

### 自定义模板变量

在自定义标记格式中，可以使用以下变量：

| 变量 | 说明 | 示例 |
|-----|------|------|
| `{model}` | AI 模型名称 | `deepseek-v3` |
| `{timestamp}` | ISO 格式时间戳 | `2026-03-27T10:30:00.000Z` |
| `{date}` | 本地日期格式 | `2026-03-27` |
| `{author}` | 作者名称 | `zhangsan` |
| `{description}` | 描述信息 | `添加用户功能` |

示例模板：
```text
// @ai-generated by {author} using {model} on {date} - {description}
```
输出结果：
```js
// @ai-generated by zhangsan using deepseek-v3 on 2026-03-27 - 添加用户功能
```

## ⚙️ 配置说明

### 完整配置示例

在 VSCode 设置（settings.json）中：

```json
{
  // 启用 Git 集成
  "aiCodeTracker.enableGitIntegration": true,
  
  // 团队成员映射
  "aiCodeTracker.teamMembers": {
    "zhangsan@company.com": "张三",
    "lisi@company.com": "李四"
  },
  
  // 自定义 AI 标记模式
  "aiCodeTracker.aiMarkPatterns": [
    {
      "name": "custom-deepseek",
      "patterns": ["@ai-generated", "// AI:", "\\[CUSTOM\\]"],
      "description": "项目自定义的 AI 标记",
      "enabled": true,
      "extractAuthor": true,
      "authorPattern": "by\\s+(\\w+)"
    }
  ],
  
  // AI 标记格式
  "aiCodeTracker.markFormat": "comment",
  "aiCodeTracker.customMarkTemplate": "// [AI-GEN] model={model} timestamp={timestamp}",
  "aiCodeTracker.defaultModel": "ai",
  
  // 自动检测阈值（连续代码行数）
  "aiCodeTracker.autoDetectThreshold": 3,
  
  // 自动标记 AI 代码
  "aiCodeTracker.autoMarkAI": false,
  
  // 周报配置
  "aiCodeTracker.weeklyReport": {
    "enabled": true,
    "dayOfWeek": 4,
    "hour": 17,
    "minute": 0,
    "outputPath": "ai-reports",
    "format": "html",
    "useGit": true,
    "autoSend": false,
    "emailRecipients": ["team-leader@company.com"]
  },
  
  // 自动添加成员时显示通知
  "aiCodeTracker.notifyOnTeamMemberAdd": true,
  
  // 块标记默认作者
  "aiCodeTracker.blockMarkAuthor": ""
}
```

### 配置项说明

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enableGitIntegration` | boolean | true | 启用 Git Blame 分析 |
| `teamMembers` | object | {} | 团队成员邮箱与名称映射 |
| `aiMarkPatterns` | array | [] | 自定义 AI 标记模式 |
| `markFormat` | string | "comment" | 标记格式: comment/tag/block/custom |
| `customMarkTemplate` | string | "// [AI-GEN] model={model}..." | 自定义标记模板 |
| `defaultModel` | string | "ai" | 默认 AI 模型名称 |
| `autoDetectThreshold` | number | 3 | 自动检测 AI 代码的阈值（行数） |
| `autoMarkAI` | boolean | false | 是否自动标记检测到的 AI 代码 |
| `blockMarkAuthor` | string | "" | 块标记的默认作者 |
| `weeklyReport.enabled` | boolean | false | 是否启用自动周报 |
| `weeklyReport.dayOfWeek` | number | 4 | 周报生成日期（0=周一, 6=周日） |
| `weeklyReport.hour` | number | 17 | 生成时间（0-23） |
| `weeklyReport.format` | string | "html" | 报告格式: html/markdown/json |
| `weeklyReport.useGit` | boolean | true | 使用 Git 历史生成报告 |
| `notifyOnTeamMemberAdd` | boolean | true | 添加成员时显示通知 |

## 👥 团队统计

### 统计维度

#### 个人维度
- 总代码行数
- AI 生成代码行数
- 人工编写代码行数
- AI 使用率
- 各文件详细统计

### 统计原理

1. **Git Blame 分析**：获取每行代码的作者信息
2. **代码标记识别**：解析多种 AI/Human 标记格式
3. **区域检测**：
   - 文件级头部标记（影响整个文件）
   - 块级标记（`@ai-generated-start` / `@ai-generated-end`）
   - 行内标记（单行 AI 代码）
4. **实时统计**：文件保存时自动更新统计

- Java (.java)

## ❓ 常见问题

### Q: 插件如何识别 AI 生成的代码？

A: 通过三种方式：

1. **自动检测**：粘贴时识别代码中的 AI 标记
2. **启发式检测**：基于代码特征（代码量、复杂度、import 语句等）智能判断
3. **手动标记**：通过注释中的 AI 标记手动标识

### Q: 为什么我的 AI 使用率显示为 0？

A: 可能的原因：

- 尚未标记任何代码为 AI 生成
- Git 配置不正确（团队统计需要）
- 项目不在 Git 仓库中
- 代码标记格式不正确

### Q: 如何统计历史代码的 AI 使用率？

A: 使用 `AI Code Tracker: 分析Git历史` 命令，插件会分析所有提交记录。

### Q: 周报可以自动发送邮件吗？

A: 目前需要配置 SMTP 服务器，后续版本会内置邮件发送功能。

### Q: 支持哪些编程语言？

A: 支持主流编程语言：JavaScript、TypeScript、Python、Java、Go、Rust、C/C++、Ruby、PHP、Vue、JSON 等。

### Q: 会影响 VSCode 性能吗？

A: 不会。插件采用增量分析和防抖机制，只在文件保存时更新统计，不影响编辑体验。

### Q: 可以导出统计数据吗？

A: 可以。周报功能支持导出 JSON 格式，方便二次处理。

### Q: 如何配置自定义的 AI 标记？

A: 使用命令 `AI Code Tracker: 配置 AI 标记模式`，添加自定义正则表达式模式。

### Q: 多人协作时如何区分不同人的 AI 代码？

A: 在标记时添加作者信息，如 `@ai-generated by zhangsan`，插件会记录并统计。

### 扩展开发

#### 添加新的 AI 标记模式

在 `markPatternManager.ts` 的 `DEFAULT_AI_PATTERNS` 中添加：

```typescript
{
  name: 'my-custom-pattern',
  patterns: [
    '//\\s*@my-ai',
    '/\\*\\s*@my-ai'
  ],
  description: '我的自定义 AI 标记',
  enabled: true,
  extractAuthor: true,
  authorPattern: 'by\\s+(\\w+)'
}
```

#### 自定义报告模板

修改 `reportFormatter.ts` 中的 `toHTML` 方法即可自定义报告样式。
